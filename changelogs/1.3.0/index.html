1.3.0: Waves and Wilds

December 30, 2023

THREE major updates in one year? Absolutely crazy stuff. Well… I’m cutting it a bit close. It’s been a while since the last one, but rest assured that the wait is well worth it.

It’s taken a while for this update to come out, and in that time… two new minor Minecraft versions have come out that I still need to update to. This update will run on 1.20.2, and I’ll be releasing a 1.20.3/1.20.4 version a bit afterwards. Still have to fix decorated pot content.

This update has plenty of new content, including a record-breaking three structures in a single update.

The theme for this update, “Waves and Wilds”, refers to the jungle/environmental features paired with the ocean ones.

Both of those themes have lots of corresponding features, so let’s dive right into the changelog!

Changes

Ocean Monument Rework

The ocean monument has been reworked for the third time

This time, I removed all the weird blocks from the palette—the coral, the copper, etc.

All painful 1×1 maze hallways have been removed

Overall, the structure is much more consistent in build style

All randomization is in 2×2 hallways now

The loot has also been tweaked:

  • Decreased gold blocks (24 —> 10)
  • Increased sponge (32 —> 64)
  • Added prismarine pottery sherds in archaeology loot in side room filled with suspicious gravel

Soul Seer

The soul seer has been entirely reworked into a redstone component

It no longer requires glowstone dust as fuel

  • Instead, the recipe has been tweaked to include glowstone

When clicked or powered, it makes mobs glow based on the block placed beneath it

  • For example, when a bone block is placed beneath, it will make all skeleton-type mobs glow
  • The comparator output from the block gives a count of how many mobs of the selected type it makes glow
  • When tinted glass is placed on top, it instead only works as a detector and does not inflict glowing

Cursed Crown

The cursed crown no longer spawns in bastions, and is instead jungle temple loot

It no longer has the “midas touch” effect, its use has been completely changed

Now it replaces 80% of your health with absorption hearts

  • These absorption hearts cannot be healed with natural regeneration, instant health, or any potion effects
  • These hearts automatically regenerate after 10 seconds of not taking damage
  • This feature is very similar to Transcendence from Risk of Rain 2, for you Risk of Rain players

Still has Curse of Binding

Has 500 durability, gives 3 armor, and can accept all helmet enchantments

Renewable by fishing for treasure within a jungle temple’s hitbox

  • This renewability mechanic is very janky and we’re currently looking into better methods

Compendium Overhaul

The compendium has been reworked for the fourth time now

It now includes a full-fledged unlock system:

  • You can toggle between unlockable and locked modes
  • Each entry has hints for what it is and how to unlock it
  • If not unlocked, they show up as silhouettes
  • References to locked entries in other entries show up as red

Images are now much higher-res

The online github wiki has also been updated to include recipes and images, giving more detail

The index is no longer six long pages, and has instead been broken into six different index categories

Many long entries that included multiple features have been broken into individual entries

  • This mainly includes loot tweaks and recipe tweaks

Several entries have also been improved and tweaked, including information that was previously left out, and making certain hints easier to understand

Generally, the compendium has become easier for me to put entries into, as images and recipes are fully auto-generated and the entry format is much better

You can no longer get infinite compendiums using a trigger

  • Instead, there is a recipe with gunpowder and a book
  • This change was partially made to prevent users from spamming the trigger to attempt to overload chunk data
  • If you don’t throw out your compendium, this shouldn’t affect anything as the compendium persists after death

Removals

Molten Mirror

I removed this feature simply because it was annoying and inconsistent, and had the potential to be overpowered.

I was going to fully rework it to utilize macros, but then I decided I didn’t want to waste my time on such a poor feature.

End City Additions

The code behind these was absolutely filthy. Nasty disgusting filthy.

I don’t want any features that use command blocks in TCC anymore—it’s just not up to par with modern mcfunction, and this postgen needed to go.

I’ve replaced them with crashed end ships, covered above.

End Crystal Dragon Head Healing

This feature was a regeneration beacon for very cheap.

It was also not the most optimized thing.

Trident Repair

Inconsistent with every other repairing method in the game, not very useful

Absorption Improvements

Removed the last piece of the absorption improvements feature, the absorption effect clearing when your hearts ran out. This was implemented by Mojang in Snapshot 23w31a.

Zombie Villager & Drowned Nugget Drops

This is for consistency with all the other zombies—they drop nuggets of their rare drop. Since zombie villagers’ is emerald, they have none. Same applies for drowned as theirs is copper.

Wandering Trader/Witch Llama Chests

These chests were difficult to check, and required the llama to have the “Tame” tag, which made their despawning methods very messy.

Without this, your worlds should be much less clogged with llamas.

Ice Overlay

Removed the ice overlay from iceologer ice/frostbloom petals

This effect was very annoying, and was simply replaced by stronger slowness

Note Block Silk Touch

This became incredibly annoying with inventory clog. Its spiritual successor is waxed note blocks.
